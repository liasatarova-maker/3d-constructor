# LuxPrint 3D Constructor

Первая рабочая версия интерактивного каталога и конструктора продукции LuxPrint.

## v0.1
- каталог продукции с категориями и поиском;
- отдельный экран конструктора без верхнего меню;
- календарь-домик как первый настраиваемый продукт;
- выбор размера, материала, печати и тиража;
- предварительный расчёт цены;
- интерактивное тестовое 3D-превью: вращение и масштаб;
- данные товаров и цены вынесены из интерфейса.

## Структура
- `index.html` — оболочка приложения;
- `src/styles.css` — интерфейс;
- `src/data.js` — каталог, материалы и базовые цены;
- `src/app.js` — каталог, конфигуратор и расчёт;
- `src/viewer.js` — тестовый 3D-viewer. Позже сюда подключим GLB/Three.js;
- `assets/models/` — будущие 3D-модели;
- `assets/textures/` — будущие текстуры.

Это прототип: цены сейчас демонстрационные и должны быть заменены на реальные производственные правила.
